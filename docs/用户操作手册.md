# 无人机培训管理系统 — 用户操作手册

## 一、软件概述

### 1.1 软件名称
**无人机培训管理系统**（Drone Training Management System）

### 1.2 软件用途
本系统是一套面向无人机培训机构的综合管理平台，支持线上课程学习与线下培训班管理。系统包含微信小程序（学员端）和 Web 管理后台（管理员端），覆盖课程购买、在线学习、考试评测、班级报名、出勤管理、合同签署、财务统计等全业务流程。

### 1.3 运行环境

| 端 | 运行环境 |
|----|----------|
| 微信小程序端 | 微信APP，基础库版本 ≥ 2.25.0 |
| Web 管理后台 | 现代浏览器（Chrome/Edge/Firefox/Safari），推荐 Chrome 90+ |
| 后端服务 | 腾讯云 CloudBase 云函数（Node.js） |

### 1.4 技术特点
- 前后端分离架构
- 云端一体化部署（CloudBase）
- 支持微信支付
- 支持手写签名电子合同
- 支持多题库随机组卷考试
- 支持培训合同在线签署

## 二、微信小程序端操作说明

### 2.1 用户登录与注册

**功能路径：小程序启动 → 登录页 → 微信授权登录 → 绑定手机号**

**操作步骤：**
1. 打开微信小程序，系统自动检测登录状态
2. 首次使用需点击「微信授权登录」，授权微信账号信息
3. 登录后需绑定手机号码（点击「绑定手机号」获取微信手机号授权）
4. 手机号绑定后即完成注册

### 2.2 首页

**功能路径：底部导航栏 → 首页**

首页展示内容包括：
- 顶部轮播图（课程推广、活动通知）
- 热门课程推荐模块
- 最新公告和通知
- 快捷入口（课程、培训班、证书）

### 2.3 课程浏览与购买

**功能路径：底部导航栏 → 课程 → 选择课程 → 课程详情**

**操作步骤：**
1. 进入课程列表，可按分类筛选（多旋翼/固定翼/直升机培训）
2. 点击课程卡片进入课程详情页，查看课程介绍、章节大纲、教师信息
3. 点击「立即购买」进入结算页面
4. 确认订单信息 → 微信支付 → 支付成功
5. 支付成功后自动跳转至培训合同签署页面
6. 阅读合同内容 → 手写签名 → 勾选同意 → 确认签署

### 2.4 在线学习

**功能路径：底部导航栏 → 个人中心 → 我的学习**

**操作步骤：**
1. 进入「我的学习」查看已购买课程列表
2. 点击课程进入学习页面，按章节顺序观看视频
3. 系统自动记录学习进度和观看时长
4. 可随时切换章节继续学习

### 2.5 培训班报名

**功能路径：底部导航栏 → 培训班 → 选择班级 → 报名**

**操作步骤：**
1. 浏览培训班列表（可按等级、类型筛选）
2. 点击班级查看详情（上课时间、授课教师、费用等）
3. 填写报名信息（姓名、身份证号、紧急联系人等）
4. 提交报名 → 支付培训费用
5. 签署培训协议 → 完成报名
6. 可在「个人中心 → 我的培训班」查看已报名班级

### 2.6 考试中心

**功能路径：个人中心 → 练习中心 → 考试中心**

**操作步骤：**
1. 进入「考试中心」查看可用考试列表
2. 点击考试进入答题界面
3. 支持选择题、判断题、填空题
4. 系统自动计时，交卷后即时评分
5. 可在「成绩」页查看考试结果和错题回顾

### 2.7 题库练习

**功能路径：个人中心 → 练习中心 → 题库练习**

**操作步骤：**
1. 选择题库（如CAAC题库、AOPA题库）
2. 练习模式：顺序练习 / 随机练习
3. 答对自动下一题，答错显示正确答案
4. 错题自动加入「错题本」供反复练习
5. 支持题目收藏功能

### 2.8 模拟考试

**功能路径：个人中心 → 练习中心 → 模拟考试**

从题库中随机抽取题目组卷，模拟真实考试环境，支持限时作答和成绩记录。

### 2.9 个人中心

**功能路径：底部导航栏 → 个人中心**

展示内容：
- 用户头像和昵称（点击可编辑头像）
- 学习统计：在学课程数、学习时长（小时）、获得证书数
- 我的学习 → 在线课程列表
- 我的培训班 → 已报名班级列表
- 我的日程 → 排课日历视图
- 练习中心 → 题库练习 / 模拟考试 / 错题本
- 我的成就 → 我的证书 / 我的合同
- 快捷工具 → 联系客服 / 关于我们 / 帮助中心 / 消息通知

### 2.10 调课申请

**功能路径：我的培训 → 调课申请**

**操作步骤：**
1. 选择要调课的课程
2. 选择调课类型（改期/转班/暂停/恢复）
3. 填写调课原因和新上课时间
4. 提交申请，等待管理员审批
5. 可在申请记录中查看审批状态

### 2.11 培训合同签署

**功能路径：购买课程后自动跳转 / 个人中心 → 我的合同**

**操作步骤：**
1. 阅读培训协议内容
2. 在手写签名区域用手指签名
3. 勾选「我已阅读并同意协议」
4. 点击「确认签署」提交
5. 签署完成后可随时在「我的合同」查看已签署合同

## 三、Web 管理后台操作说明

### 3.1 登录管理后台

**操作步骤：**
1. 浏览器访问管理后台地址
2. 输入管理员账号和密码登录
3. 首次登录建议修改默认密码

### 3.2 仪表板

**功能说明：** 登录后默认页面，展示系统概览数据

- 总用户数、总课程数、总订单数
- 本月新增学员统计
- 营收趋势图表
- 热门课程排名

### 3.3 课程管理

**功能路径：培训管理 → 课程管理**

**操作功能：**
- 课程列表：查看所有课程，支持搜索和分类筛选
- 创建课程：填写课程名称、价格、简介、封面图
- 编辑课程：修改课程信息、上下架管理
- 章节管理：添加/编辑/删除课程章节，上传视频和课件
- 教师关联：为课程分配主讲教师和助教

### 3.4 成员管理

**功能路径：培训管理 → 成员管理**

统一管理教师和学员信息：
- 成员列表：查看所有用户（学员/教师/管理员）
- 创建成员：录入新成员信息
- 编辑成员：修改成员角色、等级、状态
- 学员档案：查看学员学历、飞行经验、证书等级等信息
- 教师档案：查看教师证书编号、专长、评分等信息

### 3.5 排课出勤

**功能路径：培训管理 → 排课出勤**

- 班级排课：为每个班级安排课表（日期、时间、教师、场地）
- 出勤记录：查看和编辑学生出勤状态（出席/缺席/迟到/请假）
- 统计导出：导出出勤统计报表（CSV格式）

### 3.6 考试题库

**功能路径：培训管理 → 考试题库**

- 题库管理：创建/编辑/删除题库（支持多题库分类）
- 题目管理：添加选择题、判断题、填空题
- **批量导入**：支持 JSON 或文本格式批量导入题目
- 试卷管理：从多个题库随机抽题组卷，动态生成试卷
- 考试成绩：查看学员考试成绩和答题详情

### 3.7 订单财务

**功能路径：培训管理 → 订单财务**

- 财务概览：总订单数、总金额、已收款、待收款
- 课程订单：在线课程购买订单管理
- 培训班订单：班级报名订单管理
- 商城订单：实物商品订单管理
- 报表导出：导出订单报表（CSV格式）
- 退款处理：支持订单退款操作

### 3.8 证书管理

**功能路径：培训管理 → 证书管理**

- 证书列表：查看所有已颁发证书
- 颁发证书：为完成培训的学员颁发证书
- 证书信息：证书编号、学员姓名、课程名称、颁发日期

### 3.9 培训合同

**功能路径：培训管理 → 培训合同**

- 签署记录：查看所有合同签署记录，支持搜索和筛选
- 合同详情：查看合同内容、签名图片、签署时间
- 合同模板：编辑培训协议的 HTML 模板内容，支持变量替换（{userName}、{courseName}等）

### 3.10 班级管理

**功能路径：培训管理 → 班级管理**

- 班级列表：查看所有培训班班级
- 创建班级：设置班级名称、课程关联、人数上限、费用等
- 报名审核：审核在线报名申请（通过/拒绝）
- 线下报名：管理员协助学员完成线下报名

### 3.11 内容配置

**功能路径：系统设置 → 内容配置**

- 轮播图管理：设置首页轮播图（图片、跳转链接、排序）
- 公告管理：发布/编辑/下线系统公告
- 页面配置：自定义前台页面展示内容

### 3.12 系统设置

**功能路径：系统设置**

- 字典管理：维护系统枚举值（培训类型、证书等级等）
- 来源管理：管理学员来源渠道
- 等级管理：管理培训等级体系
- 分类管理：管理课程和班级的分类体系
- 认证配置：配置登录方式（微信授权、手机号等）
- 权限管理：管理管理员角色和权限分配

### 3.13 商城管理

**功能路径：商城管理**

- 商品管理：创建/编辑/删除实物商品
- 商品分类：管理商品分类
- 商城订单：管理商品购买订单

## 四、常见问题

**Q：无法登录小程序？**
A：检查微信版本是否过旧，建议更新至最新版。确保微信已授权小程序获取用户信息。

**Q：购买课程后无法观看？**
A：确认支付是否成功；检查是否完成培训合同签署；如仍未解决，联系客服。

**Q：考试提交后看不到成绩？**
A：交卷后成绩即时显示。如需查看历史成绩，前往考试中心查看考试记录。

**Q：管理后台登录失败？**
A：确认账号密码正确；检查浏览器cookie是否启用；清除浏览器缓存后重试。

**Q：如何批量导入题目？**
A：进入管理后台 → 考试题库 → 题库管理 → 点击「导入题目」，支持 JSON 和纯文本格式。
