# 无人机培训管理系统 — 软件设计说明书

## 一、引言

### 1.1 编写目的
本文档为无人机培训管理系统的软件设计说明书，详细描述系统的总体架构、模块划分、数据库设计、接口设计和关键技术方案。本文档供软件开发人员、系统维护人员及软件著作权审核使用。

### 1.2 项目背景
随着无人机行业的快速发展，无人机驾驶员培训需求日益增长。传统培训管理方式依赖纸质记录和人工统计，效率低、易出错。本系统旨在为无人机培训机构提供一套信息化管理工具，实现培训业务的全面数字化。

### 1.3 适用范围
本系统适用于各类无人机驾驶员培训机构，支持多旋翼、固定翼、直升机等机型的培训管理。

## 六、关键业务流程设计

### 6.1 课程购买流程

```
用户浏览课程 → 加入购物车/直接购买 → 确认订单
    → 调用 api-order.create 创建订单
    → 调用微信支付 API 发起支付
    → 用户完成支付
    → 支付回调更新订单状态
    → 自动创建课程学习权限 (course_permissions)
    → 跳转培训合同签署页
    → 用户手写签名 → 签署完成
    → 开通课程查看权限 → 进入学习
```

### 6.2 培训班报名流程

```
用户浏览班级 → 填写报名信息 → 提交报名
    → 调用 api-order.enrollClass 创建报名记录
    → 写入 class_members 表
    → 自动授权班级关联的课程权限 (course_permissions)
    → 跳转合同签署
    → 管理员审核（可选）
    → 完成报名
```

### 6.3 考试组卷流程

```
管理员配置题库 → 设置抽题规则（多题库组合）
    → 创建试卷 → 生成考试
    → 学员进入考试
    → 随机抽题（按题库配置比例）
    → 题目随机打乱顺序
    → 开始计时答题
    → 提交答案 → 自动评分
    → 记录考试成绩和错题
```

### 6.4 培训合同签署流程

```
支付/报名成功 → 调用 api-order.createContract
    → 读取合同模板（优先数据库模板，降级内置模板）
    → 变量替换 ({userName}, {courseName}, {idCard}, {phone})
    → 写入 contracts 集合
    → 用户阅读合同 → Canvas 手写签名
    → 签名导出为图片 → 上传云存储
    → 调用 api-order.signContract 更新签署状态
    → 签署完成 → 跳转学习页
```

## 七、安全性设计

### 7.1 身份认证
- 微信小程序：微信 OAuth 2.0 授权 + 手机号验证
- Web 管理后台：用户名密码登录 + 会话管理
- CloudBase Auth 提供底层认证支持

### 7.2 数据安全
- 数据库安全规则：用户数据隔离，前端只读
- 所有写操作通过云函数执行
- 敏感字段加密存储
- XSS 防护：用户输入转义处理
- CSRF 防护：请求令牌验证

### 7.3 支付安全
- 微信支付 v3 API：RSA-SHA256 签名
- 支付回调验证签名

## 八、性能优化设计

### 8.1 前端优化
- **路由懒加载**：React.lazy + Suspense 按需加载页面组件
- **代码分割**：Vite 自动拆包，框架代码长期缓存
- **图片优化**：上传前压缩（头像 ≤ 200KB），云存储 CDN 分发
- **骨架屏**：加载状态使用 Skeleton 组件提升体验
- **请求优化**：统一限流（100次/分钟）、去重、自动重试

### 8.2 后端优化
- 云函数冷启动优化：Node.js 18 运行时
- 数据库索引：为常用查询字段创建索引
- 分页查询：所有列表接口支持分页
- 请求合并：多表查询并行执行
